# shareframe-web

**React · TypeScript · Vite**

User interface, design system, room experience, screen sharing controls, responsive layouts, and frontend tests.

## Scope

- **Design system** — tokens, primitives and shared components
- **Room experience** — stage, sharing rail, presence, in-room chrome
- **Screen sharing controls** — share picker (poster frames, never live video), quality controls, active-share UI
- **Responsive layouts** — desktop, tablet and mobile breakpoints
- **Frontend tests** — component and interaction coverage
